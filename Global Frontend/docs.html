External Messaging API Reference

Send WhatsApp messages automatically from external apps, CRMs, scripts, or webhooks using FrontDesk Agent.

🔑 Authentication

All API requests must include your unique User API Key. You can find or regenerate your API Key in your Portal Dashboard or Admin Account Settings.

Provide your API key using any of the following supported methods:

  • HTTP Header (Recommended): x-api-key: YOUR_API_KEY
  • Authorization Header: Authorization: Bearer YOUR_API_KEY
  • JSON Payload or Query Parameter: "apiKey": "YOUR_API_KEY"

POST /api/external/send-message

Dispatches a WhatsApp text message to the specified recipient phone number through your active connected WhatsApp account.

Request Headers

Content-Type: application/json x-api-key: YOUR_API_KEY

Request Body Parameters

Parameter Type Required Description
receiverNumber / to string Required Recipient's WhatsApp phone number with country code (e.g. 94771234567 or +94771234567).
message / text string Required The text message content to send to the recipient.
accountId string Optional Specific WhatsApp Account ID to send from. If omitted, auto-selects your active connected WhatsApp number.
apiKey string Optional Your API Key (if not provided in HTTP headers).

  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{
    "receiverNumber": "94771234567",
    "message": "Hello from FrontDesk Agent External API!"
  }'
const response = await fetch('http://localhost:5000/api/external/send-message', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': 'YOUR_API_KEY'
  },
  body: JSON.stringify({
    receiverNumber: '94771234567',
    message: 'Hello from FrontDesk Agent External API!'
  })
});

const result = await response.json();
console.log(result);
import requests

url = "http://localhost:5000/api/external/send-message"
headers = {
    "Content-Type": "application/json",
    "x-api-key": "YOUR_API_KEY"
}
payload = {
    "receiverNumber": "94771234567",
    "message": "Hello from FrontDesk Agent External API!"
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
<?php
$ch = curl_init("http://localhost:5000/api/external/send-message");
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    "Content-Type: application/json",
    "x-api-key: YOUR_API_KEY"
]);
curl_setopt($ch, CURLOPT_POST, 1);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode([
    "receiverNumber" => "94771234567",
    "message" => "Hello from FrontDesk Agent External API!"
]));
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
curl_close($ch);
echo $response;
?>
