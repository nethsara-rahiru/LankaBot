================================================================================
  1. USER  (collection: "users")
================================================================================

  Field         | Type       | Required | Unique | Default    | Notes
  --------------|------------|----------|--------|------------|---------------------
  _id           | ObjectId   | auto     | yes    | auto       | Primary key
  name          | String     | yes      | no     | —          | LankaBot account owner
  email         | String     | yes      | yes    | —          | Login email
  password      | String     | yes      | no     | —          | bcrypt hashed password
  sessionID     | String     | no       | no     | null       | Login session
  lastLogin     | Date       | no       | no     | null       | Last login
  date          | Date       | no       | no     | Date.now   | Registration date


  Hooks / Methods:
    • pre('save')           → Hash password if modified
    • comparePassword(pwd)  → Compare password hash



================================================================================
  2. ACCOUNT  (collection: "accounts")
================================================================================

  Represents a WhatsApp business account / organization.

  Field          | Type       | Required | Unique | Default         | Notes
  ---------------|------------|----------|--------|-----------------|---------------------
  _id            | ObjectId   | auto     | yes    | auto            | Primary key
  user           | ObjectId   | yes      | no     | —               | → ref: User

  organizationName | String   | yes      | no     | —               | Business name

  phoneNumber    | String     | no       | no     | —               | WhatsApp number
  pushName       | String     | no       | no     | —               | WhatsApp display name
  profilePic     | String     | no       | no     | ""              | Profile image URL

  sessionId      | String     | yes      | yes    | —               | WhatsApp session ID

  status         | String     | no       | no     | disconnected    | disconnected | connecting | ready | qr

  lastQR         | String     | no       | no     | null            | QR data

  paused         | Boolean    | no       | no     | false           | Pause bot

  date           | Date       | no       | no     | Date.now        | Created date


  Relationships:
    • User 1:N Account



================================================================================
  3. CUSTOMER  (collection: "customers")
================================================================================

  Global customer identity.

  This data can be shared between organizations.

  Example:
  Same person contacts two companies.

  Allowed:
    ✓ Name
    ✓ Language
    ✓ Location
    ✓ Communication preference

  Not allowed:
    ✗ Orders
    ✗ Purchased products
    ✗ Previous company conversations


  Field              | Type       | Required | Default | Notes
  -------------------|------------|----------|---------|---------------------
  _id                | ObjectId   | auto     | auto    | Primary key

  phoneNumber        | String     | yes      | —       | Unique customer identifier

  name               | String     | no       | ""      | Customer name

  email              | String     | no       | ""      | Email


  globalProfile      | Object     | no       | {}      | Shared information


  ── globalProfile ─────────────────────────────────────────────────────────

  preferredLanguage  | String     | no       | "auto"  |

  location           | String     | no       | ""      |

  communicationStyle | String     | no       | ""      |


  globalPreferences  | Map        | no       | {}      |

  Example:

  {
    prefersWhatsApp:true,
    preferredTime:"evening"
  }


  globalFacts        | [Fact]     | no       | []      |


  ── Embedded: Fact ───────────────────────────────────────────────────────

  text               | String     | yes      | —       |
  category           | String     | yes      | —       | profile/preference
  confidence         | Number     | no       | 1       |
  createdAt          | Date       | no       | Date.now |


  createdAt          | Date       | no       | Date.now |



================================================================================
  4. ORGANIZATION_CONTACT
     (collection: "organization_contacts")
================================================================================

  Represents customer's relationship with one organization.

  Each organization has isolated memory.


  Field              | Type       | Required | Default | Notes
  -------------------|------------|----------|---------|---------------------

  _id                | ObjectId   | auto     | auto    |

  account            | ObjectId   | yes      | —       | → ref: Account

  customer           | ObjectId   | yes      | —       | → ref: Customer


  organizationProfile | Object   | no       | {}      |


  ── Organization Memory ───────────────────────────────────────────────────

  summary             | String    | no       | ""      | Company-specific summary


  facts               | [Fact]    | no       | []      |


  Example:

  {
    "Prefers Epson printers",
    "Usually orders monthly"
  }


  tags                | [String]  | no       | []      |

  customerType        | String    | no       | ""      | Retail/Wholesale


  lastMessageAt       | Date      | no       | Date.now |

  lastAnalyzedAt      | Date      | no       | null    |



  Relationships:

    • Account 1:N Organization_Contact
    • Customer 1:N Organization_Contact
